How It Works

1. Install and Launch

Place Power Manager in /Applications. It activates instantly, integrating with the menu bar for quick access to schedules and status.

2. Create Schedules

Use the intuitive interface to set power events, triggers, and conditions. Define actions like sleep, shutdown, or app launches with time ranges and user awareness.

3. Automate and Monitor

Triggers execute reliably. Monitor via the status menu, adjust notifying events, or interact via API, scripts, and command line.

4. Manage Remotely

Is Power Manager compatible with the latest macOS?

Yes. Version 5.12.0 includes UI updates for macOS 26, improved security responses, and optimized performance across all recent versions.

No. Non-admin users can postpone or cancel notifying triggers. Core scheduling requires standard setup privileges.

Power Manager offers multi-user support, unlimited schedules, broader actions, and advanced scripting—far exceeding built-in capabilities.
